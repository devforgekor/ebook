# Axis v4.0.0

## Scope
- 코어 파이프라인 안정화 완료
- 전면 수동 운영 (자동화 없음)

## Included
- RAW → MET → OVW → RESULT 파이프라인
- 재시도 상태 표현 (rename-only)
- Staging 수명 관리 (active / warm / purge-edge)
- 읽기 전용 결과 소비 및 CSV Export
- Runbook 및 Control‑Plane 경계 문서

## Explicitly Excluded
- 스케줄러 / 자동 실행
- TTL 기반 자동 삭제
- Control‑Plane 구현체
- 성능 튜닝
